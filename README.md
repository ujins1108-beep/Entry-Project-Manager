# 엔트리 프로젝트 매니저

내 엔트리 프로필에서 작품 전체 공개/비공개, 작품 통계, 변경 제외 목록을 관리하고 원할 경우 작품 전체 삭제를 실행할 수 있는 Chrome/Edge 확장 프로그램입니다.

## 안전 동작

- 내 프로필에서만 관리 버튼을 표시합니다.
- 작품 목록을 먼저 전부 불러오며, 전체 개수를 빠짐없이 확인하지 못하면 변경하지 않습니다.
- 엔트리 서버가 요청한 작품 수보다 적게 반환하는 경우에도 실제 반환된 개수만큼 페이지 위치를 옮겨 전체 작품 통계를 끝까지 읽습니다.
- 작품 전체 삭제는 복구할 수 없는 동작입니다. 삭제 화면에서 계정명과 작품 수를 확인하고, 최종 확인 창에 프로필 이름을 정확히 입력한 경우에만 엔트리의 삭제 요청을 한 작품씩 보냅니다.
- 삭제 화면에서도 작품 링크를 별도의 계정별 제외 목록에 추가하거나 해제할 수 있습니다. 제외된 작품은 삭제 대상 수에 포함되지 않으며 전체 삭제 후에도 유지됩니다. 공개/비공개 변경 제외 목록과는 따로 저장됩니다.
- 삭제 직전에 계정명과 전체 작품 ID 목록을 다시 확인합니다. 확인 이후 작품 목록이 바뀌면 삭제를 시작하지 않으며, 삭제 요청이 실패하면 즉시 중단합니다. 요청 처리 후 서버의 전체 목록을 다시 조회해 결과를 검증하고, 확인할 수 없는 경우 성공으로 표시하지 않습니다.
- 개발 및 검증 과정에서는 실제 계정에 삭제 요청을 보내지 않고 모의 응답만 사용합니다. 사용자가 최종 확인을 완료하면 실제 엔트리 작품이 삭제됩니다.
- 실제 변경 대상 개수와 상태를 확인받은 뒤 한 작품씩 처리합니다.
- 프로필 주소에서 대상 계정을 확인하고, 로그인 세션을 사용해 작품 상태를 조회/전환합니다. 작품 공개 상태 전환과 삭제 권한은 엔트리 서버가 검사합니다.
- 공개 상태 변경 및 삭제 요청은 엔트리 페이지의 인증 헤더를 사용합니다. 인증 정보를 읽을 수 없거나 서버가 요청을 거절하면 로그에 이유가 표시됩니다.
- 모든 변경 요청이 성공하면 대시보드에 완료 결과를 표시한 뒤 프로필 페이지를 자동 새로고침해 변경 상태를 반영합니다.
- 작품 링크를 공개/비공개 변경 제외 목록에 추가할 수 있습니다. 별도 삭제 제외 목록도 작품 전체 삭제 화면에서 설정할 수 있습니다. 각 목록은 브라우저 확장 프로그램 저장소에 계정별로 저장되며, 각각 해당 작업에서만 적용됩니다.
- 툴바 아이콘은 누르면 아무 화면도 열지 않습니다. 엔트리 프로필의 오른쪽 아래 **프로젝트 관리자** 버튼을 눌러 메인 메뉴를 열고, 작품 공개 관리, 작품 통계 또는 작품 전체 삭제를 선택합니다. 각 화면에서 해당 작업에 적용되는 제외 작품 목록을 관리할 수 있습니다. 브라우저 툴바 아이콘은 원본 `EPM-icon.png`에서 만든 16/48/128 픽셀 버전을 사용합니다.
- 작품 관리 화면은 네이비 헤더, 밝은 회색 배경, 흰색 카드와 청록색 강조 요소를 사용하며, 인페이지 헤더도 확장 프로그램의 `EPM-icon-48.png` 아이콘을 표시합니다.
- 공개/비공개 관리 화면, 통계 화면, 작품 전체 삭제 화면은 공통 헤더·기초 틀을 사용합니다. 삭제 화면은 공개/비공개 현황 대신 검증된 계정명과 작품 수, 진행 내역을 표시합니다.
- 대시보드에 공개/비공개 현황, 진행률, 작품별 처리 로그를 표시합니다.
- 별도의 작품 통계 화면에서 전체 작품을 다시 확인해 공개/비공개 작품 수와 비율, 스선 선정/인기 작품 수, 누적 좋아요/댓글 수, 좋아요 기준 최고 인기 작품을 표시합니다. 대시보드와 같은 헤더, 차트, 테마 스타일을 사용합니다. 북마크 합계는 엔트리 작품 목록 응답에 포함되지 않아 임의의 숫자로 표시하지 않습니다.
- 목록을 다시 확인할 수 있는 새로고침 버튼을 제공합니다.

## 설치

1. Chrome에서 `chrome://extensions` 또는 Edge에서 `edge://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 `ent-project-manager` 폴더를 선택합니다.
5. 엔트리에 로그인한 상태로 내 프로필 페이지를 엽니다.
6. 엔트리에 로그인한 상태로 내 프로필 페이지를 엽니다. 페이지 오른쪽 아래의 **프로젝트 관리자** 버튼을 눌러 메인 메뉴를 열고 원하는 관리 화면을 선택합니다. 작품 전체 삭제를 진행하면 되돌릴 수 없으므로, 삭제 화면에서 계정명과 작품 수를 확인하고 최종 확인 창에 계정 이름을 정확히 입력한 뒤에만 진행하세요. 툴바 아이콘을 눌러도 화면은 열리지 않습니다. 코드를 업데이트한 뒤에는 `chrome://extensions` 또는 `edge://extensions`에서 확장 프로그램의 **새로고침** 버튼을 누르고, 엔트리 프로필 탭도 새로고침해 주세요. 두 곳을 새로고침하지 않으면 이전 코드가 남아 있을 수 있습니다.

공개/비공개 전환은 엔트리 계정에 반영되며, 비공개 작품은 다른 사람에게 보이지 않을 수 있습니다.
